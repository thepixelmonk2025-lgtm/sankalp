# Sankalp Foundation Website

## Overview
This is the official website for the Sankalp Foundation, an NGO dedicated to social upliftment, education, and community development. 

## Tech Stack
- **Frontend Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: GSAP & AOS (Animate On Scroll)
- **Localization**: react-i18next (English & Marathi)
- **Routing**: React Router DOM

## Project Structure
- `/src/components`: Contains layout and shared UI components.
- `/src/pages`: Contains all route pages (Home, About, Programs, Gallery, Donate, Volunteer, Contact).
- `/src/data`: Contains static content data (e.g., team members, stats, stories).
- `/src/locales`: Contains JSON files for i18n translations.
- `/public/images`: Contains static image assets.

## Key Features
- **Bilingual**: Seamless switching between English and Marathi.
- **Responsive**: Fully optimized for mobile, tablet, and desktop viewing.
- **Accessibility**: Includes features like "Skip to main content" and semantic HTML.
- **Performance**: Static and fast-loading architecture without the need for a backend database.
